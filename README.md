# 내 비서 — 업무지시 · 알람 · 캘린더 · 일기장

대표님 개인용. 자료는 Supabase(본인만 보이는 잠금), 알람은 Supabase 안의 1분 시계가 웹 푸시로 보냅니다.
**PC 가 꺼져 있어도 휴대폰 알람이 옵니다.** 이 저장소는 화면(정적 PWA)만 담고, GitHub Pages 로 올라갑니다.

- 앱 주소: https://ai-office-mcare.github.io/my-secretary/
- 설계: `docs/DESIGN.md` · 켜는 법: `docs/SETUP.md`
- 비밀값(VAPID 개인키 · cron 비밀)은 이 저장소에 없습니다 (Supabase secrets · Vault).

## 휴대폰 필수 설정 (2026-09-22)

알람이 화면 꺼진 상태에서도 오려면 **설정 → 애플리케이션 → Chrome → 배터리 → "제한 없음"** 이어야 합니다. ("최적화" 면 첫 알림 뒤 몇 초 만에 끊깁니다.)
알림이 올 때 화면이 저절로 켜지게 하려면 보조 앱 **내 비서 화면켜기**(`wake-app/naebiseo-wake.apk`, 1.3판 2026-11-27)를 설치합니다. 웹 알림만으로는 화면을 켤 수 없습니다.
알림음을 **"일정왔어 일정왔어" 목소리**(카톡 알림처럼 빠르고 높게)로 듣는 것도 이 보조 앱이 합니다 (웹 알림은 소리를 바꿀 수 없음). 앱이 열려 있을 때는 앱이 직접 `iljeong.wav` 를 말합니다.
